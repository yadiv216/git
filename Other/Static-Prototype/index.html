THE CHALLENGE 01

Good potential.
Uneven preparation.

Students and early-career professionals lack access to personalized, affordable career guidance.

Generic resume feedback and costly interview preparation can leave candidates underprepared for placements. Pixel Petals brings those two parts of preparation together, and ties practice to the gaps found in each resume.

Why a connected approach matters ↘
ResumeFeedback that identifies specific skill, structure and ATS gaps
InterviewPractice shaped around the gaps and the role you want
PrivacyPersonal career data kept local for sensitive steps

THE RESEARCH 04

Tools are everywhere.
Connection is the gap.

Existing tools typically address resume scoring or interview practice, but not both in a connected way. Most also process data through cloud APIs, raising privacy concerns for personal career data.

THE TECHNOLOGY 06

Thoughtful by design.
Private by default.

A proposed architecture combines local inference for sensitive data with a responsive, approachable interface.

⌂
On-device inference

A small local model (for example, a quantized open-weight LLM through llama.cpp / ONNX) handles privacy-sensitive steps. Resume and interview content stay local.

LOCAL FIRST

Resume parsing

  • PyMuPDF (for PDF)
  • python-docx (for DOCX)
  • spaCy (NLP for extraction)
  • Or a lightweight local model for extraction

On-device inference

  • Small local model, such as a quantized open-weight LLM via llama.cpp / ONNX
  • PyTorch is also shown in the proposed stack
  • For privacy-sensitive steps: resume and interview content stay local

Interview Q&A generation & scoring

  • Local LLM inference or hybrid approach
  • Local for sensitive steps; cloud only for non-sensitive compute if needed
  • Examples shown: Llama (local), Mistral (local), Gemini (optional, cloud)

Frontend

  • React (or simple web app)
  • JavaScript, CSS and HTML
  • Upload UI, interview interface, results display
  • Responsive and user-friendly design

Backend

  • Python (FastAPI / Flask)
  • API to orchestrate the pipeline
  • Handle file processing, model inference, scoring and local storage

Datasets / APIs

  • Public resume datasets (e.g., Kaggle)
  • Job description datasets (Kaggle or scraped sample JDs)
  • Open interview question banks (by role/domain), including sources such as GitHub
  • Web scraping / APIs
